# OWKR 관리자 선발 시험

OWKR 내전 운영진에 지원한 사람이 Discord 계정으로 로그인해 시험에 응시하는 웹 서비스입니다. 운영진은 시험 문제, 응시 코드와 채점을 관리합니다.

**[시험 웹 열기](https://owkr-exam.vercel.app/) · [내전 규정](https://overwatch-kr.github.io/owkr-docs/) · [Discord 문의](https://discord.gg/overwatchkr)**

## 응시 방법

1. 운영진에게 시험 안내와 응시 코드를 받습니다.
2. 안내받은 Discord 계정으로 로그인하고 응시 코드를 입력합니다.
3. 시험 안내를 읽고 제한 시간 안에 답안을 작성합니다.
4. 남은 시간과 답안 저장 상태를 확인하고 답안을 제출합니다.

시험 중에는 문항별 응답 여부를 확인하고 다시 볼 문제를 표시할 수 있습니다. 응시와 결과에 관한 문의는 Discord 운영진에게 전달해 주세요.

## 운영진 기능

- 시험에 사용할 문항을 관리하고 지정된 Discord 계정에 응시 코드를 발급합니다.
- 응시 및 제출 내역을 확인하고 답안을 검토·채점합니다.
